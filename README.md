# 我的原创 Agent Skills

这里集中保存原创的 Agent Skill 与可恢复内容生产工作流。

## 包含内容

### FPV 运镜导演

路径：`skills/fpv-immersive-video-prompting/`

把 AI 视频需求转成可执行的 FPV / image-to-video 镜头调度：明确 POV、起点、路线、停靠顺序、人物数量、时间轴、角色一致性和负面约束。支持编号停靠点、红线路径控制、GPT Image 资产包，以及猫、狗、无人机、机器人等非人类视角。

### Daoist Video Skill

路径：`skills/daoist-video-skill/`

面向中文东方哲思短视频的可恢复生产流水线。它把一条视频拆成选题简报、脚本、分镜、声音预览、素材、合成、质检和发布准备等阶段，在计划、分镜和声音节点暂停等待人工确认，并用状态文件记录产物、重试次数、远程任务和费用。

## 原创范围

- `fpv-immersive-video-prompting/` 保留其独立的 MIT 许可和完整示例。
- `daoist-video-skill/` 保留原创方法论、代码、示例内容和 Skill 指令；本仓库不包含本机虚拟环境、缓存音频或带本机绝对路径的状态文件。
